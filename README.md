# Python Network Port Scanner

A Python-based network port scanner created for learning Python, networking, and cybersecurity.

## Features

- Scan a custom IP address
- Scan a custom range of ports
- Detect open TCP ports
- Use multithreading to scan ports faster
- Identify common services
- Basic banner grabbing
- Count total open ports

## Technologies

- Python
- Socket Programming
- TCP/IP
- Multithreading

## Example

Target: 127.0.0.1

Ports: 1 - 5000

Example result:

Port 135 is OPEN
Port 445 is OPEN

Total open ports found: 2
